Every layer, one scanner

SENTINEL combines static analysis, runtime hooks, and intelligent triage so you ship secure Android apps faster.

20 Specialized Agents

Auth storage, crypto, secrets, WebView, cloud, network, platform, and more — each agent is purpose-built for one class of vulnerability.

Dynamic Frida Hooks

Runtime introspection of TLS, crypto, IPC, and storage with deep hooks — catch what static analysis can't.

LLM-powered Triage

Groq → Cerebras → Ollama fallback chain filters false positives and adds confidence scores to every finding.

Privacy Mode

Toggle local-only LLM with Ollama for sensitive corp/private apps. Code never leaves your machine.

Anti-MITM Aware

Auto-detects apps that block mitmproxy (Signal, banking) and falls back to no-proxy mode gracefully.

Triage-ready Reports

Export JSON, PDF, or share live URLs. Findings include evidence, code snippets, rationale, and fix recommendations.

Built by agent specialists

Each agent owns one vulnerability class. Click in to see what they detect, false-positive rates, and key heuristics.

A_001 · Auth Storage

Detects JWTs, refresh tokens, OAuth bearers stored in plaintext SharedPreferences or unencrypted SQLite.

N_001 · Cert Pinning

Flags missing OkHttp CertificatePinner / HttpsURLConnection pinning — verifies via runtime MITM probe.

C_007 · Weak Crypto

Identifies MD5, SHA-1, DES, RC4, and ECB-mode block ciphers across Java, Kotlin, and native bridges.
