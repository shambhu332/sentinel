LLM ROUTER

Three providers, one rotating triager.

SENTINEL's FreeProviderRouter walks Groq → Cerebras → Ollama with exponential backoff. When all hosted endpoints are exhausted, it falls through to a local Ollama install. The same router pins to Ollama only when --private is set.

  • Per-provider rate-limit tracking
  • Privacy mode: zero network triage
  • Provider history logged for every scan
