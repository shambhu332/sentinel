## ⚠️  BPMN figures (#14, #15, #16) — generate in Eraser.io, not Canva

BPMN diagrams render best in a flowchart tool. Open **https://app.eraser.io → New File → Flowchart**, then either click the ✨ AI button (paste the *AI prompt*) or the `< >` code panel (paste the *Eraser DSL*). Export each as PNG and drop into the report.

Keep a consistent colour code across all three diagrams:
- 🟢 **green oval** = start event
- 🔴 **red oval** = error end
- 🩵 **cyan/aqua oval** = success end
- 🟡 **gold diamond** = gateway (`+` parallel / `X` exclusive)
- 🔵 **navy rounded rectangle** = task

## #14 — Scan Submission Workflow (BPMN) — Eraser.io

### Eraser AI prompt

```
Generate a BPMN-style flowchart titled "Scan Submission Workflow"
with three vertical swim-lanes:
  Lane 1: Customer (Developer / CI)
  Lane 2: SENTINEL Gateway
  Lane 3: Scan Queue

Flow:
- Start event (green circle) "APK Ready" in Customer lane.
- Customer task "Upload APK via Dashboard / CLI / GitHub Action".
- Gateway task "Authenticate user (JWT)".
- Exclusive gateway (diamond) "Token valid?":
   * No → end event (red circle) "401 Unauthorized".
   * Yes → continue.
- Gateway task "Validate APK signature & size".
- Gateway task "Apply tenant isolation (Postgres RLS)".
- Gateway task "Queue scan job".
- Send to Scan Queue lane → task "Job persisted".
- End event (cyan circle) "Scan-ID returned to client".

Use BPMN-standard shapes (ovals for events, rounded rectangles for tasks,
diamonds for gateways). Navy + cyan palette. Label every arrow.
```

### Eraser DSL (paste into `< >` Code panel)

```
title Scan Submission Workflow

apk_ready [shape: oval, color: green, label: "APK Ready"]
upload [label: "Upload APK\n(Dashboard / CLI / GH Action)"]
auth [label: "Authenticate user\n(JWT)"]
token_valid [shape: diamond, label: "Token valid?"]
unauth [shape: oval, color: red, label: "401\nUnauthorized"]
validate [label: "Validate APK\nsignature & size"]
isolate [label: "Apply tenant\nisolation (RLS)"]
queue [label: "Queue scan job"]
persisted [label: "Job persisted\nto queue"]
end_ok [shape: oval, color: aqua, label: "Scan-ID\nreturned"]

apk_ready > upload
upload > auth: submits APK
auth > token_valid
token_valid > unauth: No
token_valid > validate: Yes
```

## How to use these prompts — tool routing

| Figures | Tool | Why |
|---|---|---|
| Cover, #K, #1–#13, #17–#27 | **Canva (Magic Media)** | Best for stylised infographics, dashboards, SWOT / BMC / PESTLE templates. |
| **#14, #15, #16 (BPMN flows)** | **Eraser.io (Flowchart)** | Proper BPMN shapes, swim-lanes, gateways. The DSL gives pixel-perfect alignment that Canva AI struggles with. |
| Optional Figure 12 (ERD) | **Eraser.io (ERD)** | Crow's-foot notation with PK/FK styling out of the box. |

### Canva workflow

1. Canva → **Create a Design → Custom Size →** `1080 × 1080 px` (A4 portrait for the cover).
2. Click **Magic Media** (or **Apps → Text to Image**).
3. Paste a prompt from above; generate; drag onto canvas.
4. Add the caption from this file as a text layer.
5. **File → Download → PNG** → drop into the matching `🎨 Figure N` placeholder in `SENTINEL_Coursework.docx`.

If your Canva tier doesn't include Magic Media, search the template gallery using the underlined keywords — there are free templates for **SWOT, Business Model Canvas, PESTLE, value chain, empathy map, 5 Whys, POEMS, persona card**, and **PLC curve**.

### Eraser.io workflow (BPMN diagrams)

1. https://app.eraser.io → **New File → Flowchart**.
2. Either click the **✨ AI** button (paste the *Eraser AI prompt*) or click the **`< >` Code** toggle (paste the *Eraser DSL* code block).
3. For visual consistency across #14, #15, #16, keep the same colour code: 🟢 green start, 🔴 red error end, 🩵 cyan success end, 🟡 gold gateway, 🔵 navy task.
4. **File → Export → PNG → 2× resolution** (white background).
5. Drop the PNGs into the matching figure placeholders in the docx.
